# I.E. 5074 – Escáner QR conectado a Google Sheets

GitHub Pages captura el QR; Google Apps Script valida la sesión y registra la asistencia en Google Sheets.

Sigue `INSTRUCCIONES.txt`. Los archivos de Apps Script (`Code.gs` e `Index.html`) se instalan únicamente en Apps Script. Los archivos `index.html`, `app.js` y `style.css` se publican en GitHub Pages.
